# PaperBox 纸质文档管理系统

一个轻量级的个人/家庭纸质文档电子化管理系统，基于 PHP + SQLite 构建，可部署在群晖 NAS 或任意支持 PHP 的环境中。数据完全本地存储，隐私安全可控。

![License](https://img.shields.io/badge/license-MIT-blue.svg) ![PHP](https://img.shields.io/badge/PHP-7.4%2B-green.svg) ![SQLite](https://img.shields.io/badge/SQLite-3-blue.svg)

## ✨ 功能特性

### 📄 文档管理
- **多分类管理**：票据、合同、证件、说明书、医疗、保险、学校、银行、其他
- **多图片上传**：支持 jpg/png/gif/webp，单张最大 20MB，可多选
- **拖拽排序**：添加和编辑时均可拖拽调整图片顺序，支持手机端触摸操作
- **智能图片布局**：单张铺满、两张各 50%、三张各 1/3，默认显示前 6 张，超过可「展开全部」
- **首页分类联动**：选择分类后点「添加」，添加页会提示「点击填入」该分类
- **到期提醒**：可设置到期日期，首页顶部显示即将到期的文档，支持自定义提醒天数
- **回收站**：删除的文档进入回收站，可恢复或永久删除

### ✍️ Markdown 编辑器
- **双模式切换**：可视化编辑 / 实时预览
- **工具栏（电脑端）**：粗体、斜体、下划线、高亮、标题（H1/H2/H3 下拉）、引用、行内代码、代码块、无序列表、有序列表、表格、链接、图片、上标、下标、分割线、全屏编辑、语法帮助
- **对话框插入**：链接和图片通过对话框输入，图片仅支持网络地址（http/https）
- **智能操作**：选中文字点按钮自动包裹；选中多行点列表批量转换；标题可切换级别；代码块选中内容自动包裹
- **手机端**：不显示工具栏，底部保留语法提示文字和帮助链接
- **完整语法支持**：标题、引用、表格、代码块、嵌套列表（无序/有序混合）、GitHub 风格警告框（注意/提示/重要/警告/危险）、下划线、高亮、上标、下标
- **内置语法帮助页**：新窗口打开，含示例和实时渲染效果
- **快捷键**：编辑器内 `Ctrl + Enter` 快速提交
- **全屏编辑**：工具栏支持全屏编写，ESC 退出

### 💾 草稿自动保存（仅添加页）
- 输入标题/分类/标签/内容、上传/删除/排序图片时自动保存到浏览器 localStorage
- 下次打开添加页时弹窗提示恢复，显示保存时间和标题
- 选择「不恢复」时自动删除已上传但未使用的图片，避免占用空间
- 提交成功后自动清除草稿
- 编辑页不使用草稿功能（已有原始数据）

### 🔍 搜索与筛选
- **关键词搜索**：匹配标题和内容，结果高亮显示
- **分类筛选**：下拉切换即筛选，无需点击搜索，切换时保留搜索关键词和已选标签
- **标签多选**：多标签为 OR 关系（包含任一所选标签即显示），点击标签可快速筛选
- **排序功能**：按创建时间/更新时间排序，支持升序/倒序，默认创建时间倒序，切换筛选时保持排序状态
- **空结果提示**：筛选无结果时显示友好提示

### 🖼️ 图片查看器
- 点击图片放大查看
- 电脑端：鼠标滚轮缩放、拖拽平移、键盘左右键导航、ESC 关闭
- 手机端：新窗口打开原图
- 多图时显示当前序号（如 3 / 10）
- **打包下载**：详情页可将当前文档的所有图片打包为 ZIP 下载

### ⚙️ 设置与备份
- **提醒设置**：自定义到期提醒天数，快速选择 7/15/30/90 天
- **数据备份**：
  - 整站备份（数据库 + 所有图片）
  - 按时间段导出图片
  - 按标签导出图片（多选，OR 逻辑）
  - 按关键字导出图片（先查询匹配数量，再下载）
- 三种导出方式通过 Tab 切换，界面简洁

### 📱 响应式设计
- 电脑端：图片三列布局，卡片横向排列
- 手机端：图片两列布局，卡片纵向排列
- 分页器适配，手机端不换行
- 首页按数字键盘 `+` 可快速跳转到添加页

### 🔒 安全与性能
- CSRF 令牌防护（表单提交、图片上传、删除）
- SQLite WAL 模式 + 索引优化，支持十万级数据
- 上传目录防浏览，图片 MIME 类型校验
- Markdown 自动链接白名单，防止 XSS
- URL 协议白名单（仅允许 http/https/mailto/tel/相对路径）

## 📦 安装部署

### 环境要求
- PHP 7.4 或更高版本
- 启用 `pdo_sqlite`、`gd`、`fileinfo`、`zip` 扩展

### 群晖 NAS 部署
1. 「套件中心」安装 **Web Station** 和 **PHP 7.4**（或更高版本）
2. Web Station 中创建虚拟主机，指向项目目录
3. 上传项目文件到 NAS 网页根目录
4. 确保 `uploads/` 目录和 `paper.db` 有写入权限
5. 浏览器访问 `http://NAS_IP:端口` 即可使用

### 通用部署
```bash
git clone https://github.com/edielei/paperbox.git
cd paperbox
chmod 755 uploads/
chmod 666 paper.db 2>/dev/null || true
```
配置 Web 服务器（Nginx / Apache）指向项目目录，首次访问自动创建数据库。

```
├── export.php             # 数据导出（整站/时间段/标签/关键字）

├── markdown-help.php      # Markdown 语法帮助页
├── config.php             # 数据库初始化与公共函数
├── markdown.php           # SimpleMD Markdown 解析器
├── css/
│   └── style.css          # 全部样式
├── js/
│   ├── common.js          # 更多菜单、快捷键、公共交互
│   ├── editor.js          # 编辑器（上传、拖拽、工具栏、预览、快捷键、草稿）
│   └── viewer.js          # 图片查看器（缩放、拖拽、导航、展开全部）

```
